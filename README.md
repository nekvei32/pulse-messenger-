# Pulse — веб-мессенджер

Полноценный мессенджер реального времени на **Node.js + WebSocket + SQLite** с современным тёмным интерфейсом и настоящей системой аккаунтов.

## Возможности

- 🔐 **Аккаунты** — регистрация и вход с хешированием пароля (scrypt)
- 🎫 **Сессии** — токен + авто-вход; в десктоп-версии токен хранится в файле и переживает перезапуск
- 🏠 **Комнаты и каналы** — есть встроенные комнаты и можно создавать свои каналы
- 💬 **Личные сообщения** — приватные диалоги «один на один»
- 🗂️ **Три вкладки** — Комнаты / ЛС / Люди (контакты с онлайн-статусом)
- 🔍 **Поиск людей** по нику, @юзернейму или телефону
- 📸 **Отправка фото** в чат/каналы/ЛС (до 2 ГБ, файлы на диске)
- 🎤 **Голосовые сообщения** — запись с микрофона и воспроизведение
- 🎯 **Стикеры и эмодзи** — единая панель: Эмодзи / Стикеры / Гифки
- ➕ **Личные стикеры и гифки** — можно добавить свои картинки/GIF
- ⚛️ **Реакции** на сообщения (эмодзи-реакции с счётчиками)
- ✓✓ **Прочитано/не прочитано** в личных сообщениях
- 🔍 **Поиск людей** по нику, @юзернейму или телефону
- 🔎 **Поиск по чату** — фильтр сообщений текущего чата
- 👤 **Профили** — юзернейм, био, телефон, фото-аватар
- ⌨️ **Индикатор** «печатает…»
- 📜 **Постоянная история** — хранится в SQLite, переживает перезапуск сервера
- 📱 Адаптивная вёрстка

## Технологии

- **Backend:** Node.js, встроенный `http`, `ws` (WebSocket), встроенный `node:sqlite` — **без внешних баз данных и native-модулей**
- **Frontend:** чистые HTML/CSS/JS, без фреймворков
- **Desktop-приложение:** Electron — своё окно, ярлык, сервер запускается внутри
- **Безопасность:** пароли хешируются scrypt (Node crypto), сессии — случайные токены
- **Протокол:** JSON-сообщения поверх WebSocket

## Запуск

```bash
npm install   # один раз
npm run app   # запуск как отдельного десктоп-приложения (Electron)
npm start     # или запуск как веб-сервера + открыть http://localhost:3000
npm test      # автотесты
```

На рабочем столе есть лаунчер **`Pulse Chat.bat`** — запускает Pulse как отдельное приложение (проверяет зависимости и открывает окно Pulse Messenger).

## Структура

- `server.js` — сервер: БД, авторизация, комнаты, ЛС, контакты, рассылка
- `public/index.html` + `style.css` — интерфейс
- `public/app.js` — клиент: вход, сессии, рендер, ЛС
- `chat.db` — база данных (создаётся автоматически)
- `test/integration.js` — автотесты сценариев

## Хранение данных (SQLite)

Таблицы: `users` (аккаунты), `sessions` (токены), `room_messages` (история комнат), `private_messages` (личные сообщения с флагом прочитано). История переживает перезапуск сервера.

## Протокол (кратко)

| Тип | Направление | Назначение |
|-----|-------------|------------|
| `register {nick,password}` | → | создание аккаунта |
| `login {nick,password}` | → | вход |
| `auth_ok {token,user}` | ← | успех, токен сессии |
| `auth_fail {error}` | ← | ошибка авторизации |
| `hello {token,room}` | → | вход по токену |
| `init {me,rooms,history,contacts,dialogs}` | ← | полное состояние |
| `message {text}` | → | сообщение в комнату |
| `pm {to,text}` | → | личное сообщение |
| `open_dialog {with}` | → | открыть ЛС (метит прочитанным) |
| `typing {isTyping}` | ⇄ | индикатор набора |

## Для портфолио

Проект демонстрирует полный цикл бэкенда: проектирование схемы БД, аутентификацию и сессии, хеширование паролей, многопользовательскую рассылку в реальном времени, приватные диалоги — и при этом запускается локально одной командой без внешних сервисов и native-зависимостей.
